## 🎮 About The Game

**Bashith's Memory Challenge** is an interactive browser-based memory game built using **HTML, CSS, and JavaScript**.

The goal is simple:

> 🧠 Match all the identical cards before the timer reaches zero!

The game includes multiple difficulty levels, scoring, move tracking, and a restart system.

## 🕹️ How To Play

### 1️⃣ Start the Game

Open the game and choose your preferred difficulty.

### 2️⃣ Flip the Cards

Click a card to reveal its emoji.

### 3️⃣ Find the Matching Pair

Remember the card positions and find the identical emoji.

### 4️⃣ Complete the Board

Match all **8 pairs** before the timer reaches zero.

### 5️⃣ Beat Your Score

Try to complete the game with fewer moves and more remaining time! 🏆

---

## 🧮 Scoring System

Every successful pair gives you points.

Your final score is calculated using:

**Matched pairs + remaining time bonus**

So the faster you complete the game, the higher your score can be. 🚀
